1. はじめに

自動コピーは、決めたフォルダ（コピー元）の中で前回から変わったファイルだけを、決めた間隔でコピー先へコピーするアプリです。PCを起動すると自動で動き始め、タスクトレイ（画面右下）にアイコンが表示されます。

  • コピー先は、PC内のフォルダ・外付けHDD・USBメモリ・ネットワークドライブのどれでも使えます。
  • コピーの設定（ジョブ）はいくつでも作れます。
  • 変わっていないファイルは中身を読まないので、ファイルが多くても短時間で終わります。
  • コピー元でファイル名やフォルダ名を変えても、コピーし直さずにコピー先の名前を変えます。
3つの約束
  1. コピー元のファイル・フォルダは、絶対に変更・削除しません。
    例外は、あなたが「複数PCで同期」に設定したジョブだけです。このときも、他のPCのファイルを追加・更新するだけで、削除・移動・名前変更は絶対にしません。更新するときは、このPCの前の版を先に控えに残します（8-2）。
  2. コピー先のファイルを自動で削除するのは「ミラー」に設定したジョブだけです。それ以外の削除は、重複チェックの画面であなたが確認したものだけです。
  3. 削除したファイルもすぐには消さず「削除済み」フォルダに移し、保存期間（初期値30日）の間は元に戻せます。

2. 導入と初回起動

2-1. 配布フォルダから導入する（複数台で同じ設定を使う場合）

  1. 配布担当者から受け取った配布フォルダ（AutoCopy.exe・AutoCopy.setup などが入ったフォルダ）を、PCにコピーします。
  2. AutoCopy.exe をダブルクリックします。
  3. 「初回セットアップ」画面で、次の2つを入力します。
    • 配布用パスワード：配布担当者から伝えられたパスワードです。入力して 確認 を押すと、配布された設定の内容が表示されます。
    • このPCのフォルダ名：ほかのPCとコピー先が重ならないための名前です。例：山田_経理。初期値はPC名です。使えるか確認 で、ほかのPCが使っていないか確かめられます。
  4. ミラーのジョブが含まれている場合は注意が表示されます。内容を読んで「内容を理解しました」にチェックを入れます。
  5. 開始 を押します。アプリは %LOCALAPPDATA%\AutoCopy\bin にコピーされ、そこから起動します。配布フォルダはこのあと削除してかまいません。

2-2. 1台だけで使う場合

AutoCopy.exe を起動すると「初回セットアップ」画面が出ます。このPCのフォルダ名を決め（そのままでも可）、開始 を押します。続いてメイン画面でジョブを作ります（3章）。

2-3. Windows 7 の場合

Windows 7 では、先に .NET Framework 4.8 のインストールが必要です（Windows 10/11 には最初から入っています）。

  1. Windows 7 SP1 であることを確認します（「コンピューター」を右クリック →「プロパティ」で確認できます）。
  2. 配布フォルダに ndp48-x86-x64-allos-jpn.exe があれば実行します。ない場合は Microsoft のサイトから「.NET Framework 4.8」のオフライン インストーラーを入手して実行します。
  3. 再起動を求められたら再起動し、そのあと AutoCopy.exe を起動します。

3. コピー設定（ジョブ）を作る

メイン画面の ＋ ジョブを追加 を押すと「ジョブ設定」画面が開きます。既存のジョブはダブルクリックで編集できます。

3-1. 基本タブ

コピー先が新しいとき「毎回確認する」（推奨）／「上書きしない」／「常に上書き」から選びます。コピー先が古いときは自動で上書きします。

同時にコピーする数・転送速度の上限通常は初期値のままで構いません。業務中にネットワークを圧迫したくない場合は速度の上限を設定します。

3-2. 接続・重複チェックタブ

コピー元・コピー先がネットワークドライブの場合、ここで ユーザーID とパスワードを入力し 接続テスト で確認します。ID・パスワードは Windows の資格情報マネージャーに暗号化して保存され、設定ファイルやログには書かれません。

「接続できないとき」では再試行の回数と間隔を設定します（初期値：3回・30秒おき）。すべて失敗したら通知し、次の実行時刻にもう一度試します。ID・パスワードが違う場合は再試行しません（アカウントのロックを防ぐため）。

割り当てドライブ（Z:\ など）で入力した場合、保存時に \\サーバー\共有 の形に直して保存します。PC起動直後にドライブが未接続でも動くようにするためです。

3-3. テスト

テスト（コピーせずに件数を確認） を押すと、実際にはコピーせずに、コピーされる件数・除外される件数・名前変更・削除予定の件数を表示します。

4. 除外ルール

次のどれかに当てはまるファイルはコピーしません。

条件例・説明
ファイルの種類一時ファイル・動画・音楽・圧縮・実行ファイルをチェックで選べます。追加の拡張子は .log; .psd のように ; で区切ります。
ファイル名~$*; *_old.* のように *（任意の文字列）と ?（任意の1文字）が使えます。
サイズ指定したサイズより大きいファイル、0バイトのファイル。
更新日指定した日より前に更新されたファイル。
属性隠しファイル・システムファイル（初期値で除外）。
フォルダ名前だけ書くと全階層のそのフォルダ（例：node_modules）、相対パスで書くとその場所だけ（例：作業用\一時）。
例外（必ずコピー）除外ルールより優先します。例：会議録画\*.mp4 と書くと、動画を除外していても「会議録画」フォルダの mp4 はコピーします。

初期設定で Thumbs.db・desktop.ini・~$*（Office の一時ファイル）・.tmp・.bak を除外しています。

5. 普段の使い方

5-1. トレイアイコン

表示意味
青いアイコン動作中（次の実行を待っています）
青＋緑の点コピー中・重複チェック中
灰色のアイコン一時停止中
オレンジの点／点滅確認が必要（上書き確認待ち、ミラーの保留、まだ見ていない重複チェックの結果）。確認が済むまでアイコンがオレンジの「！」と交互に点滅します。
赤い点／点滅エラーがある

確認が必要になったとき

確認が必要なものが出ると、次のように知らせます。

  • 画面右下のアイコンが点滅し、マウスを重ねると「確認が必要です（〇件）」と表示されます。
  • 画面右下に「確認が必要です」のメッセージ画面が出ます（音も鳴ります）。項目をクリックするとその確認画面が開きます。確認する でいちばん上の項目、あとで（1時間） で1時間後にもう一度知らせます。作業中の画面の入力は奪いません。
  • 確認が済むまで、初期値では2時間ごとにメッセージ画面を出し直します。新しい確認が増えたときはすぐに出します。
  • メイン画面を開いているときは、タスクバーのボタンも点滅します。
  • アイコンを右クリックしたメニューの一番上にも「⚠ 確認が必要です（〇件）」が出ます。

点滅・メッセージ画面・出し直す間隔は、アプリ設定の「通知」で変えられます。重複チェックの結果は、結果の画面を一度開けば「確認済み」になります（削除するかどうかは自由です）。

アイコンをダブルクリックするとメイン画面、右クリックするとメニューが開きます。メイン画面の ×（閉じる）や「最小化」を押しても終了せず、画面右下のアイコンに入って動き続けます（タスクバーには残りません）。終了するときは、アイコンを右クリック →「終了」です。通知（画面右下に出るお知らせ）をクリックすると、該当の画面が開きます。

5-2. 手動で実行する

  • メイン画面の ▶ すべて今すぐ実行、またはトレイメニューの「すべて今すぐ実行」。
  • 特定のジョブだけ：メイン画面でジョブを選んで 選んだジョブを実行、またはトレイメニューの「ジョブを選んで実行」。
  • デスクトップの「強制データ送信」：ダブルクリックすると、すべてのジョブをすぐにコピーします（初回セットアップで作れます。アプリ設定の「デスクトップのショートカット」でも作れます）。前の版で作った「自動コピー（今すぐ実行）」は、自動で「強制データ送信」に名前を変えます。ジョブごとのショートカットは「強制データ送信（ジョブ名）」です。

ショートカットは次のコマンドでも作れます。

動作コマンド
すべて実行AutoCopy.exe /run
指定したジョブだけ実行AutoCopy.exe /run "ジョブ名"
重複チェックAutoCopy.exe /dupcheck
更新版があるか確かめるAutoCopy.exe /checkupdate

5-3. 一時停止

トレイメニューまたはメイン画面の「一時停止」から、30分・1時間・3時間・再開するまで、を選べます。一時停止は保存しないので、PCを再起動すると必ず自動で再開します。一時停止中でも手動実行はできます。

5-4. コピー先で消したファイルを戻したいとき

このアプリは速さのため、変わっていないファイルのコピー先を毎回は確認しません。コピー先のファイルを手で消した場合は、メイン画面でジョブを右クリックし「全体を再確認して実行」を選ぶと、コピー先にないファイルをコピーし直します。

6. 名前を変えたときの動き

コピー元でファイル名・フォルダ名を変えたり、同じドライブ内で移動したりすると、次の実行でコピー先でも同じように名前を変えます。ファイルをコピーし直さないので、大きなフォルダの名前を変えても一瞬で終わります。確認は出ません。ログには RENAME として記録されます。

  • コピー先に新しい名前のファイルが既にある場合など、安全に名前を変えられないときは、名前変更せず通常のコピーをします。
  • USBメモリ（FAT32・exFAT）や一部のNASがコピー元の場合は、サイズ・更新日時・ファイルの先頭と末尾の一致で判断します。判断できないときは通常のコピーをします。
  • 別のドライブへの移動など、ここで追従できなかったものは重複チェック（9章）で見つかります。

7. 上書き確認が出たとき

コピー先のファイルの方が新しい場合（コピー先で誰かが直接編集した場合など）、自動実行中に勝手に上書きせず「確認待ち」にして通知します。通知またはメイン画面の 確認する から「上書きの確認」画面を開きます。

選択動作
上書きする（このPCの方を使う）コピー元のファイルで上書きします。「上書きする前に…退避に残す」にチェックがあれば、古いファイルを退避します。
共有フォルダの方を使う（同期のみ）同期のジョブで、共有フォルダの版をこのPCに取り込みます。このPCの版は控えに残ります。
今回はスキップ上書きしません。コピー元のファイルがまた変わるまで聞きません。
今後も上書きしないこのファイルは今後ずっとコピーしません。
閉じる（後で決める）確認待ちのまま残ります。

8. ミラー

ミラーにすると、コピー元で削除したファイル・フォルダはコピー先からも削除されます。コピー元で誤って消した場合も、コピー先から消えます。バックアップ目的なら「追加・更新のみ」をおすすめします。

ジョブ設定で「ミラー」を選ぶと注意画面が出ます。次の実行で削除される予定の件数を確認し、「内容を理解しました」にチェックを入れてから ミラーにする を押します。ミラーのジョブには、画面上で常に「ミラー」と表示されます。

安全のための仕組み

  • 削除したファイルは コピー先\_AutoCopy\削除済み に移し、保存期間（初期値30日）の間は元に戻せます。
  • 削除するのは、このアプリがコピーしたファイルだけです。コピー先に人が直接置いたファイルは削除しません。
  • コピー元が空のときや接続できないときは、何も削除しません（USBの抜き忘れなどで全部消える事故を防ぎます）。
  • 一度の実行で100件、またはコピー先の10%を超える削除（10件以下は除く）は保留し、確認を求めます。通知またはトレイメニューの「ミラーの保留中の削除」から、削除する／今回は削除しない を選びます。
  • コピー先で更新されたファイルは削除しません。除外ルールに当てはまるファイルも削除しません。

8-2. 複数PCの同期（例外）

同期は例外的な使い方です。通常の「追加・更新のみ」「ミラー」は1台のPCがコピー先を使い、コピー元には一切書き込みません。同期にしたジョブだけは、他のPCが共有フォルダに入れたファイルが、このPCのコピー元フォルダにも入ってきます。

ジョブ設定の基本タブで「複数PCで同期」を選ぶと、説明が表示されます。コピー先には、同期するすべてのPCから見える共有フォルダ（NAS など）を指定し、すべてのPCで同じジョブ（配布設定で配ると簡単です）を使います。メイン画面では方式が「同期（複数PC）」、フォルダが「⇄」で表示されます。

起きたこと動き
このPCでファイルを追加・更新共有フォルダへコピーします（いつもと同じ）。
他のPCがファイルを追加・更新共有フォルダから、このPCのフォルダに取り込みます。このPCに古い版があれば、置き換える前に控え（%LOCALAPPDATA%\AutoCopy\sync-backup）にコピーして残します（保存期間は削除済みと同じ、初期値30日）。
同じファイルを両方で変更どちらも上書きせず「上書きの確認」に出します。「このPCの方を使う」「共有フォルダの方を使う」「今回はスキップ」から選びます。初めて同期するときに、同じ名前で中身の違うファイルが両方にある場合も同じです。
ファイルを削除削除はどちらにも伝えません。このPCで消したファイルは、他のPCがその後で更新しない限り取り込み直しません。
名前を変更共有フォルダでも名前を変えます。他のPCには新しい名前で取り込まれ、古い名前のファイルはそのPCに残ります（削除は伝えないため）。
使用中のファイル開いているファイルは置き換えず、次の実行で取り込みます。
  • 同期のジョブでは、コピー先の {フォルダ名} は使えません（PCごとに別のフォルダになってしまうため）。ミラーとも同時には使えません。
  • 同期の共有フォルダには他のPCのファイルがあるため、重複チェックと「大きいファイルの重複」の省略は行いません。
  • ログには、取り込んだファイルが SYNCIN として記録されます。

9. 重複チェックと削除・復元

コピー先に無駄なファイルがないかを定期的に調べ（初期値：毎日12:00）、見つかったら通知します。削除は必ず確認画面で選んでから行います。

種類説明と初期状態
フォルダ名の変更の可能性古い名前のフォルダの中身が、別のフォルダとほぼ同じ（90%以上一致）。古い方をフォルダごと削除候補にします（チェックあり）。
ファイル名の変更・移動コピー元にない古い名前のファイルと、今のファイルの中身が同じ。古い方を削除候補にします（チェックあり）。
中身が同じ（情報のみ）コピー元にも両方あるため削除できません（消しても次回またコピーされるため）。
孤立ファイルコピー元にないファイル。設定で表示した場合のみ。チェックなし。
空のフォルダコピー先にある、中にファイルが1つもないフォルダのうち、コピー元に同じフォルダがないもの（コピー元でフォルダを移動・削除した後に残った空のフォルダなど）。チェックあり。空のフォルダが入れ子になっているときは、いちばん上のフォルダだけを表示します。コピー元にも同じ空のフォルダがあるもの、隠し・システムフォルダ、コピー作業中のものは対象外です。ジョブ設定の「接続・重複チェック」タブで探さないようにもできます。
  1. 通知、またはトレイメニュー／メイン画面の「重複チェック」から結果画面を開きます。
  2. 削除するものにチェックを入れます（「今の名前」は削除できません。同じ中身のものは必ず1つ残ります）。
  3. 選んだものを削除… を押し、件数とサイズを確認して OK を押します。

空のフォルダも、ほかの削除と同じく「_AutoCopy\削除済み」へ移すだけなので元に戻せます。削除の直前にもう一度中を確かめ、その間にファイルが入ったフォルダは削除しません。コピー元のフォルダは、空であっても削除しません。

元に戻す

重複チェック画面の 元に戻す…、またはメイン画面でジョブを右クリック →「削除済み・退避から元に戻す…」を開き、日時を選んで 選んだものを元に戻す を押します。元の場所に同じ名前のファイルがあるときは「(復元)」を付けて戻します。

9-2. 大きいファイルの重複（コピーせずにテキストで場所を書き置き）

コピー元の中に、中身が同じ大きいファイル（初期値 10MB 以上）が複数あると、コピー先には1つ目だけをコピーし、2つ目以降は「元の名前.重複.txt」というテキストを置きます。容量の節約になります。

  • テキストには、コピー元のファイルの場所、中身が同じファイルのコピー先での保管場所、サイズ、更新日時、MD5（中身の指紋）が書いてあります。必要なときは保管場所のファイルをコピーして、元の名前に変えて使います。
  • 中身は同じ大きさのファイルだけを読んで、ファイル全体で比べます。1つ目には、すでにコピー済みのものを優先します。すでに普通にコピーしてある2つ目以降のファイルは、そのまま残します（コピー先から消しません）。
  • コピー元でどちらかの中身が変わったり、1つ目が消えたりすると、次の実行で普通にコピーし直し、テキストは片付けます。
  • ジョブ設定の基本タブ「大きいファイルの重複」で、オン・オフと対象の大きさを変えられます。オフにすると、次の実行で普通にコピーします。ログには DEDUP として記録されます。

10. 複数台で使う

10-1. 配布フォルダを作る（配布担当者）

  1. 配布担当者のPCでジョブを作り、「保存場所」を「配布設定に含める」にします。コピー先には {フォルダ名} を入れてください（例：\\nas01\backup\{フォルダ名}\経理）。入れないと、複数のPCが同じ場所に書き込んで互いのファイルを上書きするおそれがあります。
  2. アプリ設定で「ログ保管先」（例：\\nas01\自動コピー\logs）を設定します。
  3. アプリ設定の 配布フォルダを作成… を押し、配布設定の名前・配布用パスワード（4文字以上）・作成する場所を入力します。ネットワークの ID・パスワードは暗号化して含められます。
  4. Windows 7 のPCに配る場合は、ndp48-x86-x64-allos-jpn.exe を AutoCopy.exe と同じフォルダに置いておくと、配布フォルダに同梱されます。
  5. できた配布フォルダを各PCにコピーします。配布用パスワードは、配布フォルダとは別の方法（口頭など）で伝えてください。

10-2. 設定を変えて配り直す

配布担当者のPCで設定を直し、もう一度「配布フォルダを作成」します（版が1つ上がります）。各PCでは、新しい配布フォルダの AutoCopy.exe を起動するか、アプリ設定の 配布設定を読み込む… で AutoCopy.setup を選びます。このPCのフォルダ名・このPCだけのジョブは消えません。

10-3. このPCのフォルダ名を変える

アプリ設定の「このPCのフォルダ名」の 変更… から変えられます。コピー先とログ保管先にある今のフォルダも、新しい名前に変えます（再コピーはしません）。

10-4. 全PCのログをまとめて見る

各PCは「ログ保管先\フォルダ名」にログを書きます。ログ画面で「すべてのPC」を選ぶと、全PCのログを時刻順にまとめて表示し、上部に各PCの最新状態（前回の実行・エラーの有無）を表示します。ログ保管先に一時的に届かない間は、PC内に溜めておき、届くようになったら送ります。

10-5. プログラムの自動更新

NAS の配布フォルダ（または「更新版の置き場所」）に新しい AutoCopy.exe を置くと、各PCが自動で新しい版に入れ替えます。各PCを回って入れ直す必要はありません。

  1. 新しい版の AutoCopy.exe（デジタル署名付き。10-6）を、配布フォルダに上書きで置きます。操作説明書.html などもあれば一緒に置きます（自動で入れ替わります）。
  2. 各PCは1時間ごと（起動の2分後にも）に置き場所を確かめ、新しい版があれば入れ替えて起動し直します。コピー中や、画面を開いている間は終わるまで待ちます。
  3. 入れ替えると「新しい版に更新しました」と通知し、ログに UPDATE と記録します。すぐ確かめたいときは、アイコンの右クリック →「更新を確認」。
  • 置き場所：配布フォルダ（NAS 上）から初回セットアップしたPCは、その配布フォルダを自動で使います。アプリ設定の「自動更新」で変えられます。配布フォルダを作るときに NAS を指定すると、配布設定にも入ります。
  • 版：置き場所の版が今の版より新しいときだけ更新します（古い版には戻しません）。版はアイコンの右クリックメニューやアプリ設定で確認できます。
  • 安全のため：今の版にデジタル署名があるときは、同じ証明書で署名され、署名の後で中身が変えられていない版だけを使います。違う証明書・署名なし・改ざんされたものは使わず、通知とログで知らせます。
  • 入れ替える前の版は AutoCopy.exe.old として同じフォルダに残ります。困ったときは、自動コピーを終了してから AutoCopy.exe を消し、.old を AutoCopy.exe に名前を変えると元に戻せます（このとき置き場所の新しい版を消すか、自動更新をオフにしてください）。

10-6. デジタル署名

AutoCopy.exe には発行元「自動コピー」のデジタル署名が付いています。エクスプローラーでファイルを右クリック →「プロパティ」→「デジタル署名」タブで確認できます。署名があると、配布の途中で中身が変えられていないことを確かめられ、自動更新もこれを使って安全な版だけを受け入れます。

  • この証明書は自分たちで作った証明書（自己署名）です。そのままでは「発行元：不明」や SmartScreen の警告が出ることがあります。配布フォルダの 署名証明書を登録.bat を各PCで右クリック →「管理者として実行」すると、このPCが「自動コピー」の署名を信頼するようになり、警告が出なくなります（任意。登録しなくても自動コピーと自動更新は動きます）。
  • この証明書はプログラムの署名専用で、ほかの証明書を発行することはできません。
  • どのPCでも警告が出ないようにするには、認証局から購入するコード署名証明書が必要です。購入した場合も、build.bat の署名の設定を差し替えるだけで使えます（ただし証明書が変わるため、最初の1回は各PCで入れ直すか、自動更新をオフにしてから配ってください）。
  • 新しい版を作るときは、署名用のファイル（自動コピー_署名用.pfx）とパスワードで署名します（ビルド手順.txt）。この .pfx とパスワードは厳重に保管してください（これがあれば「自動コピー」の名前で署名できます）。

11. ログの見方

ログはPC内（%LOCALAPPDATA%\AutoCopy\logs）に日別に保存され、ログ保管先を設定していればそちらにも送られます。ログ画面では期間・ジョブ・種類・文字で絞り込み、CSV（Excel で開けます）に書き出せます。

PCごとのコピー容量を集計する

ログ画面で期間（と必要ならジョブ）を選び、「PC」で「すべてのPC」を選んで 表示 を押してから、コピー容量の集計 を押します。各PCがコピーした容量（新規コピーと上書きのファイルサイズの合計）、ファイル数、名前変更・削除・エラーの件数、実行回数が、容量の多い順に表示されます。いちばん下の行が全体の合計です。

  • 「ジョブごとに分ける」にチェックすると、PC×ジョブごとに表示します。
  • 名前変更はコピーし直さないため、容量には含みません。
  • CSVに書き出す で、バイト単位の数値を Excel で開ける形式で保存できます。

グラフで見る

集計画面の上のタブを切り替えると、同じ内容をグラフで確認できます。

  • PCごとのグラフ：PCごとのコピー容量を横棒で表示します。青が新規コピー、オレンジが上書きです。容量の多い順に並び、21台以上ある場合は20位以下を「その他」にまとめます。
  • 日ごとのグラフ：日ごとのコピー容量を縦棒で表示し、PCごとに色分けして積み上げます。容量の多い7台を色分けし、残りは灰色の「その他」にまとめます。期間が92日を超えると月ごとの表示に切り替わります。同じフォルダ名を複数のPCが使っている場合は「フォルダ名（PC名）」として別々に表示します。
  • 棒にマウスを重ねると、PC名・日付・容量が表示されます。
  • グラフを画像で保存 で、表示中のグラフを PNG 画像として保存できます（報告書への貼り付け用）。
  • 期間やジョブを変えたいときは、ログ画面で条件を変えて 表示 → コピー容量の集計 を押し直します。

どこの何をたくさんコピーしたかを見る

集計画面の残りのタブで、コピーした容量の割合と大きいファイルを確認できます。上の帯は全体を100%としたときの割合で、下の横棒は容量の多い順です（上位7項目に色が付き、残りは灰色）。

  • 場所別の割合：最初は PC ごとの割合です。棒をクリックすると、そのPCのジョブ → フォルダ → ファイルの順に中へ入れます。↑ 上のフォルダへ で戻ります。
  • 種類別の割合：拡張子ごと（.xlsx（Excel・表）、.mp4（動画）など）の割合です。
  • 大きいファイル：コピーした容量の多いファイルの一覧（上位1,000件）です。場所（PC＼ジョブ＼フォルダ）、コピーした回数、1回のサイズも表示します。同じファイルを何度も上書きしている場合（Outlook の .pst など）は、回数×サイズがコピー容量になります。CSVに書き出す で一覧を保存できます。

コピー先の容量の内訳を調べる

今コピー先（またはコピー元）のどこに何が入っていて容量を使っているかは、メイン画面の 容量の内訳（またはジョブの右クリック →「容量の内訳を調べる」）で調べられます。ジョブと「コピー先／コピー元」を選んで 調べる を押します。フォルダの中を読むだけで、ファイルの変更・削除はしません。

  • フォルダ別の割合：フォルダとファイルの割合です。フォルダの棒をクリックすると中に入れます。1つのフォルダに小さいファイルがたくさんある場合は「ほかのファイル ○件」にまとめます。
  • 種類別の割合：拡張子ごとの割合です。
  • 大きいファイル：サイズの大きいファイルの一覧（上位1,000件）と、全体に占める割合です。行をダブルクリック（または 場所を開く）すると、エクスプローラーでそのファイルを選んだ状態で開きます。
  • コピー先の「_AutoCopy」フォルダ（隠しフォルダ）は、重複チェックやミラーで削除したファイル（削除済み）と上書き前の退避です。保存期間（初期値30日）を過ぎると自動で消えます。
  • ファイルが多いと時間がかかります（目安：10万ファイルで数十秒〜数分。ネットワークの速さによります）。調べている間は、見つけたファイル数・容量と今調べているフォルダが表示されます。中止 を押すといつでも止められます（Esc キーでも止まります）。中止したときは途中までの結果は表示せず、前に調べた結果があればそのまま残ります。

12. こんなときは

状況対処
「〇〇に接続できません」と通知が出るネットワーク・NAS の電源・ケーブルを確認してください。直ったら次の実行時刻に自動で再開します。すぐ試すには通知をクリックするか「今すぐ実行」を押します。
「ID またはパスワードが違います」ジョブ設定の「接続・重複チェック」タブで ID・パスワードを入れ直し、接続テストで確認してください。
「ドライブ E:\ がありません」外付けドライブ・USBメモリが接続されているか確認してください。
「このフォルダ名は他のPCが使っています」アプリ設定で「このPCのフォルダ名」を別の名前に変えてください。
「使用中のため次回に回します」開いているファイルは次の実行でコピーします。何度も続く場合はファイルを閉じてください。
「コピー元が空のため…削除を止めました」ミラーの安全機能です。コピー元のドライブ・フォルダが正しいか確認してください。
「ログを保管先に送れていません」ログ保管先への接続を確認してください。ログはPC内に残っているので失われません。
Windows 7 で起動しない.NET Framework 4.8 をインストールしてください（2-3）。
アイコンが見当たらない画面右下の「^」を押すと隠れたアイコンが表示されます。ドラッグして常に表示させることもできます。
コピーされないファイルがある除外ルールに当てはまっていないか、ジョブ設定の テスト →「除外されるファイルを表示」で確認してください。

13. アンインストール

  1. トレイメニューの「終了」でアプリを終了します。
  2. アプリ設定で「Windows にサインインしたら自動で起動する」のチェックを外して OK を押すか、終了後に次のフォルダを削除します。
  3. %LOCALAPPDATA%\AutoCopy と %APPDATA%\AutoCopy を削除します。デスクトップのショートカットも削除します。
  4. 保存した ID・パスワードは、コントロールパネル →「資格情報マネージャー」→「Windows 資格情報」の AutoCopy: で始まる項目を削除します。

コピー先のファイルは削除されません。不要なら コピー先\_AutoCopy フォルダも削除できます。
