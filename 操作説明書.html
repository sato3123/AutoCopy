1. はじめに

自動コピーは、決めたフォルダ（コピー元）の中で前回から変わったファイルだけを、決めた間隔でコピー先へコピーするアプリです。PCを起動すると自動で動き始め、タスクトレイ（画面右下）にアイコンが表示されます。

  • コピー先は、PC内のフォルダ・外付けHDD・USBメモリ・ネットワークドライブのどれでも使えます。
  • コピーの設定（ジョブ）はいくつでも作れます。
  • 変わっていないファイルは中身を読まないので、ファイルが多くても短時間で終わります。
  • コピー元でファイル名やフォルダ名を変えても、コピーし直さずにコピー先の名前を変えます。
3つの約束
  1. コピー元のファイル・フォルダは、絶対に変更・削除しません。
    例外は、あなたが「複数PCで同期」に設定したジョブだけです。このときも、他のPCのファイルを追加・更新します。削除は自動では反映せず、「同期：削除の確認」で承認した場合だけ、このPCのファイルを控えへ移します。更新するときは、このPCの前の版を先に控えに残します（8-2）。
  2. コピー先のファイルを自動で削除するのは「ミラー」に設定したジョブだけです。それ以外の削除は、重複チェックの画面であなたが確認したものだけです。
  3. 削除したファイルもすぐには消さず「削除済み」フォルダに移し、保存期間（初期値30日）の間は元に戻せます。

2. 導入と初回起動

2-1. 配布フォルダから導入する（複数台で同じ設定を使う場合）

  1. 配布担当者から受け取った配布フォルダ（AutoCopy.exe・AutoCopy.setup などが入ったフォルダ）を、PCにコピーします。
  2. AutoCopy.exe をダブルクリックします。
  3. 「初回セットアップ」画面で、次の2つを入力します。
    • 配布用パスワード：配布担当者から伝えられたパスワードです。入力して 確認 を押すと、配布された設定の内容が表示されます。
    • このPCのフォルダ名：ほかのPCとコピー先が重ならないための名前です。例：山田_経理。初期値はPC名です。使えるか確認 で、ほかのPCが使っていないか確かめられます。
  4. ミラーのジョブが含まれている場合は注意が表示されます。内容を読んで「内容を理解しました」にチェックを入れます。
  5. 開始 を押します。アプリは %LOCALAPPDATA%\AutoCopy\bin にコピーされ、そこから起動します。配布フォルダはこのあと削除してかまいません。

2-2. 1台だけで使う場合

AutoCopy.exe を起動すると「初回セットアップ」画面が出ます。このPCのフォルダ名を決め（そのままでも可）、開始 を押します。続いてメイン画面でジョブを作ります（3章）。

2-3. Windows 7 の場合

Windows 7 では、先に .NET Framework 4.8 のインストールが必要です（Windows 10/11 には最初から入っています）。

  1. Windows 7 SP1 であることを確認します（「コンピューター」を右クリック →「プロパティ」で確認できます）。
  2. 配布フォルダに ndp48-x86-x64-allos-jpn.exe があれば実行します。ない場合は Microsoft のサイトから「.NET Framework 4.8」のオフライン インストーラーを入手して実行します。
  3. 再起動を求められたら再起動し、そのあと AutoCopy.exe を起動します。

3. コピー設定（ジョブ）を作る

メイン画面の ＋ ジョブを追加 を押すと「ジョブ設定」画面が開きます。既存のジョブはダブルクリックで編集できます（ダブルクリックしても有効／無効は変わりません）。

新しく作ったジョブ・複製したジョブは「無効」で作られます（自動では実行されません）。テスト（コピーせずに結果を確認） で内容を確かめてから、メイン画面でジョブの左のチェックを入れて有効にしてください。配布設定を取り込んだときも、新しく加わったジョブは「無効」で取り込みます（取り込み済みのジョブは、このPCで決めた有効／無効をそのまま使います）。

はじめての設定（①〜④の順に）と「詳しい設定」（v1.16.4）

  • 新しいジョブの画面では、上に「① コピー元フォルダ → ② コピー先フォルダ → ③ コピーの方式 → ④ 実行のタイミング」の順番が出ます。基本タブの項目にも同じ番号が付いています。ほかの項目は初期値のままで使えます。
  • 画面の上の 「詳しい設定も表示する」 にチェックを入れると、時間帯・起動後の初回・名前変更と上書きのルール・同時にコピーする数・転送速度・除外の細かい条件（対象を限定・サイズ・日付・属性・例外）・接続できないときの再試行・コピー先の整理で探すもの などが表示されます。初期値と違う値にしている項目があるジョブは、自動で「詳しい設定」を表示します（隠れたまま気づかない、ということがないように）。チェックの状態は次に開いたときにも残ります。表示を切り替えても、設定の値は変わりません。
  • 「0 = 自動」のような数の入力はやめ、「自動で決める」「速度を制限する」などのチェックや、よく使う大きさの一覧（1 KB・10 KB・100 KB・1 MB・10 MB）から選ぶ形にしました。
  • 灰色で操作できない項目にマウスを重ねると、「操作できない理由：〜」が出ます（例：「ミラーのときだけ使います」「『複数PCで同期』では、コピー先の整理は行いません」）。
  • 各画面の下の左端の ？ 説明 で、その画面の説明（この操作説明書の該当の箇所）を開きます。
  • 新しいジョブを保存すると、「テストしてから有効にする」「今すぐ有効にする」「あとで（無効のまま）」を選ぶ画面が出ます。「テストしてから有効にする」では、実行結果の予測（コピーはしません）を見た後で、有効にするかを確かめます。無効のジョブは、メイン画面の「結果」の列に「無効（自動ではコピーしません。左のチェックで有効）」と橙色で出ます。

ボタンの見分け方（全画面共通）

  • 青いボタン：その画面の主な操作（すべて今すぐ実行・OK・検索・この内容で今すぐ実行・確認する）。
  • 赤いボタン：削除など、元に戻しにくい操作（ジョブの削除・選んだものを削除・移す など）。押すと必ず確認のメッセージが出ます。
  • 橙のボタン：注意が必要な操作（上書きする・共有フォルダの方を使う・中止・元に戻す・取り消す・ミラーにする など）。押すと確認のメッセージが出ます（ミラーは「内容を理解しました」のチェックが確認の代わりです）。
  • ボタンには種類ごとに同じアイコンを付けています（▶実行、■中止、＋追加、ごみ箱＝削除、フォルダ＝開く・参照、虫めがね＝探す、矢印の輪＝最新にする・もう一度、下向き矢印＝CSVに書き出す、じょうご＝条件で選ぶ、× ＝閉じる など）。
  • 似た操作のボタンは近くに並べ、種類の違うまとまりの間は少し空けています。削除などの赤いボタンは、「閉じる」のすぐ隣にならないよう離して置いています。

一覧の使い方（全画面共通）

  • 並べ替え：一覧の見出しをクリックすると、その列で並べ替えます。もう一度クリックすると逆の順になります（見出しに ▲ 昇順／▼ 降順 が付きます）。日時の列は最初のクリックで新しい順、容量・件数は数の大きさの順に並びます。空欄はいつも後ろです。
  • すべてにチェック：チェック欄のある一覧では、チェック欄の真上にあるチェックのアイコンで、すべてにチェック／すべて外す を切り替えます。アイコンは、すべてチェック＝☑、一部だけ＝■、なし＝□ の形に変わります。メイン画面のジョブ一覧では、このアイコンですべてのジョブの有効／無効をまとめて切り替えます（確認が出ます）。
  • 条件で選ぶ：チェック欄のある一覧（上書きの確認・重複チェック結果・フォルダ内の重複・同期の削除の確認・「今後も上書きしない」の一覧）では、チェックのアイコンの横の 条件で選ぶ… で、条件に合う行をまとめて選べます。
    • 条件：名前・場所に含む文字（または含まない文字。「;」で区切るとどれか1つ）、拡張子、大きさ（〇以上・〇以下）、更新日時（〇より前・〇以降）、種類（状態・判定・ジョブ・拡張子など、一覧ごとに選べるもの）。指定したものすべてに当てはまる行が「条件に合うもの」で、件数がその場で表示されます。
    • 条件に合うものにチェック／条件に合うもののチェックを外す／条件に合うものだけチェック（ほかは外す）。
    • 重複の画面では、各まとまりで残すもの（パスが短いもの／更新日時が新しいもの／更新日時が古いもの／条件に合うもの）を選んで 各まとまりで1つ残して、ほかにチェック もできます。例：「個人」フォルダのものを残したい → 名前・場所に「個人」、残すもの「上の条件に合うもの」。どの選び方でも、同じ中身のファイルは必ず1つ残ります。
    • 前回の条件は、次に開いたときにも残っています。
  • ダブルクリック：行をダブルクリックしても、チェックは変わりません（チェック欄そのものをクリックしたときだけ変わります）。
  • 列の幅：一覧の幅に合わせて自動で調整します（画面が狭いときは縮め、広いときは長い列を広げます）。見出しの境目をドラッグして手で変えることもできます。

3-2. 接続・コピー先の整理タブ

「コピー先の整理（重複チェック）」は、コピー先に残った古い名前のコピー・空のフォルダなどを探して知らせる機能です（9章）。小さいファイルを探さないときは、一覧から大きさを選びます（「小さいファイルも探す（すべて）」が初期値）。

コピー元・コピー先がネットワークドライブの場合、ここで ユーザーID とパスワードを入力し 接続テスト で確認します。ID・パスワードは Windows の資格情報マネージャーに暗号化して保存され、設定ファイルやログには書かれません。

「接続できないとき」では再試行の回数と間隔を設定します（初期値：3回・30秒おき）。すべて失敗したら通知し、次の実行時刻にもう一度試します。ID・パスワードが違う場合は再試行しません（アカウントのロックを防ぐため）。

割り当てドライブ（Z:\ など）で入力した場合、保存時に \\サーバー\共有 の形に直して保存します。PC起動直後にドライブが未接続でも動くようにするためです。

3-3. 実行結果の予測（コピーせずに結果を確認）

ジョブ設定の テスト（コピーせずに結果を確認）、メイン画面の 結果の予測、またはジョブの右クリック →「コピーせずに結果を確認」で、実際にはコピーせずに、実行したら何がどうなるかを一覧で確認できます。コピー先・コピー元・前回までの記録は一切変えません（ジョブ設定から開いた場合は、まだ保存していない変更も反映して調べます）。

4. 除外ルール

次のどれかに当てはまるファイルはコピーしません。

条件例・説明
ファイルの種類一時ファイル・動画・音楽・圧縮・実行ファイルをチェックで選べます。追加の拡張子は .log; .psd のように ; で区切ります。
ファイル名~$*; *_old.* のように *（任意の文字列）と ?（任意の1文字）が使えます。
サイズ指定したサイズより大きいファイル、0バイトのファイル。
更新日指定した日より前に更新されたファイル。
属性隠しファイル・システムファイル（初期値で除外）。
フォルダ名前だけ書くと全階層のそのフォルダ（例：node_modules）、相対パスで書くとその場所だけ（例：作業用\一時）。
例外（必ずコピー）除外ルールより優先します。例：会議録画\*.mp4 と書くと、動画を除外していても「会議録画」フォルダの mp4 はコピーします。

初期設定で Thumbs.db・desktop.ini・~$*（Office の一時ファイル）・.tmp・.bak を除外しています。

  • 一覧から選ぶ（v1.16.4）：コピー元にある種類から選ぶ… で、コピー元にあるファイルの種類（拡張子）を、件数・容量の大きい順に一覧から選んで除外に加えられます（コピー元は読むだけです）。例外（必ずコピー）も ファイルを選んで追加… でファイルを選んで加えられます。
  • 件数がその場で分かる：タブの上に「この設定で：コピーする 〇件・除外 〇件（コピー元 〇件）」と出ます。条件を変えると少し後に数え直します。ファイルがとても多いとき（30秒で数えきれないとき）は「数えきれませんでした」と出るので、テスト で確かめてください。

確認が必要なものが出ると、次のように知らせます。

  • 画面右下のアイコンが点滅し、マウスを重ねると「確認が必要です（〇件）」と表示されます。
  • 画面右下に「確認が必要です」のメッセージ画面が出ます（音も鳴ります）。項目をクリックするとその確認画面が開きます。確認する でいちばん上の項目、あとで（1時間） で1時間後にもう一度知らせます。作業中の画面の入力は奪いません。
  • メッセージ画面は、初期値では60秒たつと自動で閉じます（「あと〇秒で自動的に閉じます」と表示。マウスを重ねている間は閉じません）。秒数・閉じないようにする設定は、アプリ設定の「通知」で変えられます。自動で閉じても、確認が済むまでアイコンの点滅は続きます。
  • 確認が済むまで、初期値では2時間ごとにメッセージ画面を出し直します。新しい確認が増えたときはすぐに出します。
  • メイン画面を開いているときは、タスクバーのボタンも点滅します。
  • アイコンを右クリックしたメニューの一番上にも「⚠ 確認が必要です（〇件）」が出ます。

点滅・メッセージ画面・出し直す間隔は、アプリ設定の「通知」で変えられます。重複チェックの結果は、結果の画面を一度開けば「確認済み」になります（削除するかどうかは自由です）。エラーは、メッセージ画面やお知らせから開いて確認すれば、点滅が止まります（その後も同じエラーが続くときは、また点滅させずに回数だけ数えます）。確認が済むと、アイコン・メッセージ画面・Windows の通知センターに残った通知もすぐに元に戻ります。

6. 名前を変えたときの動き

コピー元でファイル名・フォルダ名を変えたり、同じドライブ内で移動したりすると、次の実行でコピー先でも同じように名前を変えます。ファイルをコピーし直さないので、大きなフォルダの名前を変えても一瞬で終わります。確認は出ません。ログには RENAME として記録されます。

  • コピー先に新しい名前のファイルが既にある場合など、安全に名前を変えられないときは、名前変更せず通常のコピーをします。

8. ミラー

ミラーにすると、コピー元で削除したファイル・フォルダはコピー先からも削除されます。コピー元で誤って消した場合も、コピー先から消えます。バックアップ目的なら「追加・更新のみ」をおすすめします。

ジョブ設定で「ミラー」を選ぶと注意画面が出ます。次の実行で削除される予定の件数を確認し、「内容を理解しました」にチェックを入れてから ミラーにする を押します。ミラーのジョブには、画面上で常に「ミラー」と表示されます。

安全のための仕組み

  • 削除したファイルは コピー先\_AutoCopy\削除済み に移し、保存期間（初期値30日）の間は元に戻せます。
  • 削除するのは、このアプリがコピーしたファイルだけです。コピー先に人が直接置いたファイルは削除しません。
  • コピー元が空のときや接続できないときは、何も削除しません（USBの抜き忘れなどで全部消える事故を防ぎます）。
  • 一度の実行で100件、またはコピー先の10%を超える削除（10件以下は除く）は保留し、確認を求めます。通知またはトレイメニューの「ミラーの保留中の削除」から、削除する／今回は削除しない を選びます。
  • コピー先で更新されたファイルは削除しません。除外ルールに当てはまるファイルも削除しません。
  • コピー元で読めなかったフォルダ（アクセス権がない・途中で接続が切れたなど）の中のファイルは、削除しません。結果は「一部失敗」になり、ログに【アクセス拒否】などと記録されます（v1.14）。

コピー・上書きの安全のための仕組み（すべてのジョブ）

  • コピーはいったん一時ファイル（.ckpart）に書き、ディスクへの書き込みを確定させてから置き換えます。途中で電源が切れたり、強制終了したり、ディスクがいっぱいになったりしても、元のファイルは変わりません。上書きに失敗したときも、元のファイルに戻します。
  • コピーしている間にコピー元のファイルが変わった（保存し直された）ときは、少し待ってやり直します。変わり続けるときはコピーせず、次の実行に回します。
  • 中止したときは、置き換える直前でも止めます（コピー先は元のままです）。
  • 更新されたばかりのファイル（1時間以内）や、他のアプリが書き込みのために開いているファイルは、コピーの後で中身を読み直して確かめます。大きさ・更新日時が同じまま中身が変わっていても、やり直します（v1.15）。
  • 上書きの途中でPCの電源が切れたり、強制終了したりしたときは、次の起動（またはジョブの実行）のときに、元のファイルに自動で戻します（v1.15）。
  • 置き換える直前に、コピー先が予定を立てたときのままか確かめます。他のPC・アプリが書き換えていたら上書きせず、次の実行で確かめ直します。同じファイルに別のPC（v1.15 以降）が書き込み中のときは、終わるのを待ちます（コピー先に一時的に 〜.cklock ができ、終わると消えます）（v1.15）。
  • 上書きに失敗したときは、読み取り専用などの属性も元に戻します（v1.15）。
  • 同じフォルダ（コピー先が同じ・一方のコピー先がもう一方のコピー元）を使うジョブは同時に動かさず、メイン画面に「待機中（「〇〇」が終わってから実行）」と出して、終わってから実行します。
  • 重複チェック・フォルダ内の重複ファイル検索で削除・移動するときは、その直前に、残す方のファイルと1バイトずつ中身を比べ、同じものだけを外します。
  • 記録（状態ファイル）が壊れたときは、壊れたファイルを .corrupt-日時 として残し、前回保存した内容（.bak）から戻して知らせます。どちらも読めないときは記録を作り直し、その間はミラー・同期の削除の候補を出しません。

8-2. 複数PCの同期（例外）

同期は例外的な使い方です。通常の「追加・更新のみ」「ミラー」は1台のPCがコピー先を使い、コピー元には一切書き込みません。同期にしたジョブだけは、他のPCが共有フォルダに入れたファイルが、このPCのコピー元フォルダにも入ってきます。

ジョブ設定の基本タブで「複数PCで同期」を選ぶと、説明が表示されます。同期の動きは よく使う組み合わせから選べます（v1.16.4）：「共有フォルダのファイルを受け取る（初期値）」＝他のPCのファイルを取り込み、このPCだけにあるファイルは送らない／「すべてのPCで同じにする（追加したファイルも送る）」＝このPCで追加したファイルも他のPCへ送る／「自分で選ぶ（下の2つ）」。コピー先には、同期するすべてのPCから見える共有フォルダ（NAS など）を指定し、すべてのPCで同じジョブ（配布設定で配ると簡単です）を使います。メイン画面では方式が「同期（複数PC）」、フォルダが「⇄」で表示されます。

起きたこと動き
このPCでファイルを追加（このPCにだけあり、共有フォルダにないファイル）初期値では、共有フォルダにはコピーしません。ジョブ設定の「このPCにだけあって、共有フォルダにないファイル」で「共有フォルダへコピーする」を選ぶとコピーします。コピーしなかったものは、実行結果の予測に「共有へ送らない（同期の設定）」と表示されます。
このPCでファイルを更新（両方にあるファイル）共有フォルダへコピーします（いつもと同じ）。
他のPCがファイルを追加（共有フォルダにだけあり、このPCにないファイル）初期値では、このPCに取り込みます。ジョブ設定の「共有フォルダにだけあって、このPCにないファイル」で「このPCにはコピーしない」を選ぶと取り込みません。取り込まなかったものは、実行結果の予測に「取り込まない（同期の設定）」と表示されます。
他のPCがファイルを更新（両方にあるファイル）共有フォルダから、このPCのフォルダに取り込みます。このPCに古い版があれば、置き換える前に控え（%LOCALAPPDATA%\AutoCopy\sync-backup）にコピーして残します（保存期間は削除済みと同じ、初期値30日）。
同じファイルを両方で変更どちらも上書きせず「上書きの確認」に出します。「このPCの方を使う」「共有フォルダの方を使う」「今回はスキップ」から選びます。初めて同期するときに、同じ名前で中身の違うファイルが両方にある場合も同じです。
ファイルを削除すぐには伝えず、「削除の確認」に出します（下の表）。確認するまでは、どちらのファイルもそのままにします（このPCで消したファイルを取り込み直すこともしません）。
名前を変更共有フォルダでも名前を変えます。他のPCには新しい名前で取り込まれ、古い名前のファイルは「削除の確認」に出ます。
使用中のファイル開いているファイルは置き換えず、次の実行で取り込みます。

削除の確認（同期）

一方で削除されたファイルが見つかると、アイコンが点滅し「同期：削除されたファイル 〇件 の扱いを選んでください」と知らせます。お知らせ・メッセージ画面・トレイメニューの「同期：削除の確認」から画面を開き、ファイルにチェックを入れて選びます。

どこで削除されたか削除する を選んだとき残す（戻す） を選んだとき
このPCで削除共有フォルダからも外します（共有フォルダの _AutoCopy\削除済み へ移すので、保存期間の間は戻せます）。他のPCには、それぞれのPCで「削除の確認」が出ます。すぐに、共有フォルダからこのPCへ戻します（「取り込まない」設定でも戻ります）。
共有フォルダで削除（他のPCが削除）このPCからも外します（消さずに控え %LOCALAPPDATA%\AutoCopy\sync-backup へ移します）。すぐに、このPCから共有フォルダへ戻します（「共有へ送らない」設定でも戻ります）。

見つけた後でファイルが変更されていた場合（もう一方に戻っていた場合も）は、削除せずに知らせ、次の実行で通常どおりコピー・取り込みします。閉じる（後で決める） で、確認待ちのまま残せます。

  • 同期のジョブでは、コピー先の {フォルダ名} は使えません（PCごとに別のフォルダになってしまうため）。ミラーとも同時には使えません。
  • 同期の共有フォルダには他のPCのファイルがあるため、重複チェックと「大きいファイルの重複」の省略は行いません。
  • ログには、取り込んだファイルが SYNCIN として記録されます。
  • 共有フォルダの確認を速くする（v1.14）：ファイルが多い共有フォルダでは、毎回すべてを調べると時間がかかります。ジョブ設定の「共有フォルダの詳しい確認を、前回から〇分以内なら省略する」（初期値30分）の間は、前回調べた内容を使い、このPCの変更だけを送ります。他のPCが自動コピーで共有フォルダを変えると印（_AutoCopy\sync-stamp.txt）が変わるので、次の実行ですぐに詳しく確かめ直します。
    ※ 自動コピーを使わずに共有フォルダを直接変えた場合は、最大で設定した時間だけ取り込みが遅れます。0 にすると毎回詳しく確認します。「全体を再確認」では必ず詳しく確認します。

9. コピー先の整理（重複チェック）と削除・復元

保存先をエクスプローラーで開く（v1.16.5）：重複ファイル・削除の候補の一覧（コピー先の整理の結果・フォルダの重複ファイル探し・ミラーの保留中の削除・同期の削除の確認・元に戻す）で、行を右クリック →「エクスプローラーで保存先を開く」を選ぶと、そのファイルを選んだ状態でエクスプローラーが開きます。「場所（パス）をコピー」で場所を貼り付けられます。開くだけで、ファイルは変えません。ファイルがもう無いときは、残っているいちばん近いフォルダを開いてお知らせします。
「重複」の付く機能は3つあります（v1.16.4 で名前を分かりやすくしました）。
・コピー先の整理（重複チェック）：ジョブのコピー先に残った、古い名前のコピー・空のフォルダ・中身が同じファイルを探して知らせます（この章）。
・フォルダの重複ファイル探し：コピーとは関係なく、指定したフォルダの中で同じファイルを探します（9-1）。
・大きいファイルの重複をテキストに置き換える：コピー元の中の、中身が同じ大きいファイルの2つ目以降をコピーせず、場所を書いたテキストにして容量を節約します（9-2）。
メイン画面では 重複・整理 ▾ にまとめています。

コピー先に無駄なファイルがないかを定期的に調べ（初期値：毎日12:00）、見つかったら通知します。削除は必ず確認画面で選んでから行います。

種類説明と初期状態
フォルダ名の変更の可能性古い名前のフォルダの中身が、別のフォルダとほぼ同じ（90%以上一致）。古い方をフォルダごと削除候補にします（チェックあり）。
ファイル名の変更・移動コピー元にない古い名前のファイルと、今のファイルの中身が同じ。古い方を削除候補にします（チェックあり）。同じフォルダの中（または同じフォルダからフォルダへ）のものは、1つのまとまり「ファイル名の変更　フォルダ「〇〇」の中で 〇件」にまとめます。
中身が同じ（情報のみ）コピー元にも両方あるため削除できません（消しても次回またコピーされるため）。
孤立ファイルコピー元にないファイル。設定で表示した場合のみ。チェックなし。
空のフォルダコピー先にある、中にファイルが1つもないフォルダのうち、コピー元に同じフォルダがないもの（コピー元でフォルダを移動・削除した後に残った空のフォルダなど）。チェックあり。空のフォルダが入れ子になっているときは、いちばん上のフォルダだけを表示します。コピー元にも同じ空のフォルダがあるもの、隠し・システムフォルダ、コピー作業中のものは対象外です。ジョブ設定の「接続・コピー先の整理」タブで探さないようにもできます。

小さいファイルの重複を探さない（v1.16.3）：ジョブ設定の「接続・コピー先の整理」タブの「小さいファイル」で、〇 KB より小さいファイルの「ファイル名の変更・移動」（古いコピー）と「中身が同じ」を探さないようにできます（初期値 0 = すべて探す。前の版の設定もすべて探します）。設定ファイルなど、小さくて数の多いファイルの重複が一覧を埋めてしまうときに使います。

  1. 通知、またはトレイメニュー／メイン画面の「重複チェック」から結果画面を開きます。
  2. 削除するものにチェックを入れます（「今の名前」は削除できません。同じ中身のものは必ず1つ残ります）。チェック欄の真上のアイコンで、削除できるものすべてにチェック／すべて外す ができます。
  3. 選んだものを削除… を押し、件数とサイズを確認して OK を押します。

件数がとても多いとき（名前の変更が何万件もあるときなど）は、画面が重くならないよう、最初の約5,000行だけを表示します（上に「最初の約〇行だけ表示しています」と出ます）。表示したものを処理してから 今すぐ再チェック を押すと、続きが出ます。

空のフォルダも、ほかの削除と同じく「_AutoCopy\削除済み」へ移すだけなので元に戻せます。削除の直前にもう一度中を確かめ、その間にファイルが入ったフォルダは削除しません。コピー元のフォルダは、空であっても削除しません。

9-1. フォルダの重複ファイル探し（コピーと関係なく）

コピーのジョブとは関係なく、指定したフォルダの中で同じファイル（中身・ファイル名・更新日時・大きさを組み合わせて決められます）を探せます。メイン画面の 重複・整理 ▾ →「フォルダの重複ファイル探し」、コピー先の整理の結果の画面の フォルダを指定して探す…、またはアイコンの右クリック →「フォルダの重複ファイル探し…」で開きます。

  1. フォルダを入力するか 参照… で選びます。ジョブのフォルダ ▾ から、ジョブのコピー元・コピー先も選べます。ネットワークのフォルダも使えます。
  2. 同じとみなす基準を選びます（v1.16.3）。選んだものがすべて同じファイルを「重複」とします。
    • 中身（初期値）：ファイル全体が同じ。大きさ → 先頭と末尾 → 全体の順に比べるので、名前が違っても中身が同じものを見つけます。
    • ファイル名：名前が同じ（フォルダは問いません。大文字・小文字は区別しません）。
    • 更新日時：2秒以内の差は同じとみなします（NAS・USBメモリの丸めのため）。
    • 大きさ：バイト数が同じ（「中身」を選ぶと、大きさも同じなので選べません）。
    例：「ファイル名」＋「更新日時」で、同じ名前・同じ日時のコピーを探す。「中身」＋「ファイル名」で、名前も中身も同じものだけを探す。中身を選ばないときはファイルを読まないので、ファイルが多くても速く探せます（一覧のまとまりに「中身は未確認」と出ます）。
  3. 「サブフォルダも含める」と、小さいファイルの一覧（「小さいファイルも探す（すべて）」／「100 KB より小さいファイルは探さない」など）を選んで 検索 を押します。探すだけでは、ファイルは何も変わりません（途中で中止もできます）。
  4. 中身が同じファイルを「まとまり」ごとに、空く容量の大きい順に表示します。各まとまりの先頭（パスが短いもの・古いもの）が「残す候補」で、選んだ理由（「パスが最短」「いちばん古い」「名前の順」）も表示します。行をダブルクリックすると、エクスプローラーでそのファイルを選んだ状態で開きます。
  5. 移したいものにチェックを入れます。チェック欄の真上のアイコンで「各まとまりで1つ残して、ほかにすべてチェック」できます。同じ中身のものは必ず1つ残ります。
  6. チェックしたものを移す… を押すと、消さずにそのフォルダの _AutoCopy\重複で削除\日時（隠しフォルダ）へ移します。どの基準で探したときも、移す直前に残すファイルと中身を比べ、中身が同じものだけを移します（名前・日時が同じでも中身が違うものは移さず、理由を表示します）。元に戻すときは、移したファイルのフォルダを開く から元の場所へ戻してください。この中は自動では消えないので、不要になったら手で削除してください。

自動コピーのコピー元のフォルダ（またはその中）のファイルは、元データを守るため移しません（探して一覧を見ることはできます）。CSVに書き出す で一覧を保存できます。結果はログ（種類 DUPCHECK・DELETE）にも残ります。

元に戻す

メイン画面の 元に戻す ▾（ジョブを1つ選んでいればそのジョブ、選んでいなければジョブを選ぶ一覧）、アイコンの右クリック →「元に戻す（削除・上書きしたファイル）」→ ジョブ名、コピー先の整理の画面の 元に戻す…、またはジョブを右クリック →「元に戻す（削除・上書きしたファイル）…」を開き、日時を選んで 選んだものを元に戻す を押します。元の場所に同じ名前のファイルがあるときは「(復元)」を付けて戻します。

9-2. 大きいファイルの重複をテキストに置き換える（中身が同じ大きいファイル）

コピー元の中に、中身が同じ大きいファイル（初期値 10MB 以上）が複数あるとき、2つ目以降を「コピーしない」で「元の名前.重複.txt」というテキストに置き換えられます。テキストには、1つ目がコピー先のどこに保管されているかなどが書いてあります。容量と時間の節約になります。

扱い（ジョブ設定）動き
見つけたら毎回選ぶ（初期値）見つけると、2つ目以降は選ぶまでコピーせずに待ち、「確認が必要です」でお知らせします（1つ目は普通にコピーするので、中身はコピー先にあります）。重複チェックの画面で、ファイルごとに「テキストにする」か「普通にコピーする」を選びます。
自動でテキストにする選ばずに、2つ目以降を自動でテキストにします。
使わない重複していても、すべて普通にコピーします。

選び方（重複チェックの画面）

  1. お知らせをクリックするか、メイン画面の 重複チェック を開きます。「大きいファイルの重複：「〇〇」と中身が同じ」というまとまりに、1つ目（コピーするもの）と、扱いを選ぶファイルが並びます。
  2. 選ぶファイルにチェックを入れて、選んだ重複をテキストにする（コピーしない） か 選んだ重複を普通にコピーする を押します。
  • 普通にコピー済みの重複も選べます：重複チェックを行うと、すでに普通にコピーしてある重複も「普通にコピー済み（テキストにすると〇〇 空く）」として出ます。テキストにすると、コピー先のファイルは「_AutoCopy\削除済み」へ移り（保存期間の間は元に戻せます）、代わりにテキストを置きます。
  • 一度選んだ扱いは覚えていて、次からは聞きません。ファイルの中身が変わったときは、もう一度選んでもらいます。
  • 「実行結果の予測」では「重複：扱いを選ぶ」と表示されます。
  • 1つ目（コピーして残すもの）の決め方：① 先にコピーしたもの（コピー先にコピー済みのものがあれば、初めてコピーした日時が早いもの）→ ② パス名が短いもの → ③ ファイル名が短いもの、の順で決めます。
  • 中身は同じ大きさのファイルだけを読んで、ファイル全体で比べます。コピー元のファイルは読むだけで変えません。
  • コピー元でどちらかの中身が変わったり、1つ目が消えたりすると、次の実行で普通にコピーし直し、テキストは片付けます。同期のジョブでは使いません。ログには DEDUP として記録されます。

10. 複数台で使う

10-1. 配布フォルダを作る（配布担当者）

  1. 配布担当者のPCでジョブを作り、「保存場所」を「配布設定に含める」にします。コピー先には {フォルダ名} を入れてください（例：\\nas01\backup\{フォルダ名}\経理）。入れないと、複数のPCが同じ場所に書き込んで互いのファイルを上書きするおそれがあります。
  2. アプリ設定で「ログ保管先」（例：\\nas01\自動コピー\logs）を設定します。
  3. アプリ設定の 配布フォルダを作成… を押し、配布設定の名前・配布用パスワード（12文字以上。前の版で作った短いパスワードの配布設定も、そのまま使えます。その場合は作り直しをお勧めします）・作成する場所を入力します。ネットワークの ID・パスワードは暗号化して含められます。
  4. Windows 7 のPCに配る場合は、ndp48-x86-x64-allos-jpn.exe を AutoCopy.exe と同じフォルダに置いておくと、配布フォルダに同梱されます。
  5. できた配布フォルダを各PCにコピーします。配布用パスワードは、配布フォルダとは別の方法（口頭など）で伝えてください。

10-2. 設定を変えて配り直す

配布担当者のPCで設定を直し、もう一度「配布フォルダを作成」します（版が1つ上がります）。各PCでは、新しい配布フォルダの AutoCopy.exe を起動するか、アプリ設定の 配布設定を読み込む… で AutoCopy.setup を選びます。このPCのフォルダ名・このPCだけのジョブは消えません。

10-3. このPCのフォルダ名を変える

アプリ設定の「このPCのフォルダ名」の 変更… から変えられます。コピー先とログ保管先にある今のフォルダも、新しい名前に変えます（再コピーはしません）。

10-4. 全PCのログをまとめて見る

各PCは「ログ保管先\フォルダ名」にログを書きます。ログ画面で「すべてのPC」を選ぶと、全PCのログを時刻順にまとめて表示し、上部に各PCの最新状態（前回の実行・エラーの有無）を表示します。ログ保管先に一時的に届かない間は、PC内に溜めておき、届くようになったら送ります。

10-5. プログラムの自動更新

NAS の配布フォルダ（または「更新版の置き場所」）に新しい AutoCopy.exe を置くと、各PCが自動で新しい版に入れ替えます。各PCを回って入れ直す必要はありません。

  1. 新しい版の AutoCopy.exe（デジタル署名付き。10-6）を、配布フォルダに上書きで置きます。操作説明書.html などもあれば一緒に置きます（自動で入れ替わります）。
  2. 各PCは1時間ごと（起動の2分後にも）に置き場所を確かめ、新しい版があれば入れ替えて起動し直します。コピー中や、画面を開いている間は終わるまで待ちます。
  3. 入れ替えると「新しい版に更新しました」と通知し、ログに UPDATE と記録します。すぐ確かめたいときは、アイコンの右クリック →「更新を確認」。
  • 置き場所：配布フォルダ（NAS 上）から初回セットアップしたPCは、その配布フォルダを自動で使います。アプリ設定の「自動更新」で変えられます。配布フォルダを作るときに NAS を指定すると、配布設定にも入ります。
  • 版：置き場所の版が今の版より新しいときだけ更新します（古い版には戻しません）。版はアイコンの右クリックメニューやアプリ設定で確認できます。
  • 安全のため：デジタル署名がない版には更新しません（v1.14）。有効期限が切れた証明書・コード署名用でない証明書・発行元までたどれない証明書で署名された版も使いません（v1.15）。今の版に署名があるときは、同じ証明書で署名され、署名の後で中身が変えられていない版だけを使います（今の版に署名がないときは、正式な「自動コピー」の証明書で署名された版だけ）。違う証明書・署名なし・改ざんされたものは使わず、通知とログで知らせます。
  • 更新に失敗したとき：新しい版が起動できなかったとき（3分以内に動き始めなかったときも）は、自動で前の版（説明書などの関連ファイルも）に戻して起動し直し、「更新に失敗したため、前の版に戻しました」と知らせます。失敗した版は AutoCopy.exe.failed として残し、その版には二度と更新しません（もっと新しい版を置くと更新します）。
  • 入れ替える前の版は AutoCopy.exe.old として同じフォルダに残ります。困ったときは、自動コピーを終了してから AutoCopy.exe を消し、.old を AutoCopy.exe に名前を変えると元に戻せます（このとき置き場所の新しい版を消すか、自動更新をオフにしてください）。

10-6. デジタル署名

AutoCopy.exe には発行元「自動コピー」のデジタル署名が付いています。エクスプローラーでファイルを右クリック →「プロパティ」→「デジタル署名」タブで確認できます。署名があると、配布の途中で中身が変えられていないことを確かめられ、自動更新もこれを使って安全な版だけを受け入れます。

  • この証明書は自分たちで作った証明書（自己署名）です。そのままでは「発行元：不明」や SmartScreen の警告が出ることがあります。配布フォルダの 署名証明書を登録.bat を各PCで右クリック →「管理者として実行」すると、このPCが「自動コピー」の署名を信頼するようになり、警告が出なくなります（任意。登録しなくても自動コピーと自動更新は動きます）。
  • この証明書はプログラムの署名専用で、ほかの証明書を発行することはできません。
  • どのPCでも警告が出ないようにするには、認証局から購入するコード署名証明書が必要です。購入した場合も、build.bat の署名の設定を差し替えるだけで使えます（ただし証明書が変わるため、最初の1回は各PCで入れ直すか、自動更新をオフにしてから配ってください）。
  • 新しい版を作るときは、署名用のファイル（自動コピー_署名用.pfx）とパスワードで署名します（ビルド手順.txt）。この .pfx とパスワードは厳重に保管してください（これがあれば「自動コピー」の名前で署名できます）。

11. ログの見方

ログはPC内（%LOCALAPPDATA%\AutoCopy\logs）に日別に保存され、ログ保管先を設定していればそちらにも送られます。CSV（Excel で開けます）にも書き出せます。

エラー・確認の対応状況を見る

ログ画面の 「エラー・確認の対応状況」 タブ（またはアイコンの右クリック →「エラー・確認の対応状況」）で、エラー・上書きの確認・重複・ミラーの削除保留・同期の削除のそれぞれが、未対応か対応済みか、いつ発生し、いつ・どう対応したかを一覧で見られます。

  • 上に「いま残っている確認」（上書きの確認・大きいファイルの重複の扱い・重複チェックの削除候補・ミラーの削除保留・同期の削除・未対応のエラーの件数）が出ます。
  • 「表示：□未対応 □対応済み」と「種類」で絞り込めます。上の期間・ジョブでも絞り込みます（未対応のものは期間に関係なく表示します）。
  • 列：状態／発生日時／対応日時／ジョブ／種類／内容／どう対応したか（確認しました・その後正常に実行できました・手で対応済みにしました など）／回数。見出しのクリックで並べ替えられます。
  • ダブルクリックで該当の画面を開きます。右クリックで「対応済みにする」「未対応に戻す」ができます。
  • このタブはこのPCの記録です。対応したことはログにも種類 HANDLED（対応状況）として残り、ログ保管先に送られるので、「ログ」タブで「すべてのPC」を読み込み、種類「エラー・確認と対応状況」または「対応状況のみ」を選ぶと、全PCの対応状況を見られます。

ログを絞り込む（設備・ジョブ・時刻）

  • 読み込むログ：「このPC」または「すべてのPC（ログ保管先）」。
  • 期間：今日／直近1時間／直近24時間／直近7日／直近30日／期間を指定。日付と時刻（分まで）で指定できます（例：2026/11/05 09:00〜12:30）。
  • 設備（PC）・ジョブ：読み込んだログに出てくる PC（フォルダ名）とジョブから選べます。
  • 種類・検索：種類（エラーのみ・コピー・上書き など）、内容の文字で絞り込みます。
  • 「すべてのPC」のときに上に出る PC の一覧（フォルダ名・PC名・最終更新・ジョブ・結果）の行をクリックすると、その設備・ジョブのログに絞り込みます。最終更新の見出しで、更新が古い順・新しい順に並べ替えられます。

PCごとのコピー容量を集計する

ログ画面で期間（と必要ならジョブ）を選び、「PC」で「すべてのPC」を選んで 表示 を押してから、コピー容量の集計 を押します。各PCがコピーした容量（新規コピーと上書きのファイルサイズの合計）、ファイル数、名前変更・削除・エラーの件数、実行回数が、容量の多い順に表示されます。いちばん下の行が全体の合計です。

  • 「ジョブごとに分ける」にチェックすると、PC×ジョブごとに表示します。
  • 名前変更はコピーし直さないため、容量には含みません。
  • CSVに書き出す で、バイト単位の数値を Excel で開ける形式で保存できます。

12. こんなときは

エラーのお知らせには、原因に合わせて「次にすること：〜」を付けて表示します（v1.16.4。ネットワークの切断・空き容量の不足・アクセス拒否・使用中・パスが長すぎる・フォルダが見つからない・IDやパスワードの誤り）。

状況対処
「〇〇に接続できません」と通知が出るネットワーク・NAS の電源・ケーブルを確認してください。直ったら次の実行時刻に自動で再開します。すぐ試すには通知をクリックするか「今すぐ実行」を押します。
「【ネットワークの切断】ネットワークにつながっていないため…」Wi-Fi・LAN が切れています。Wi-Fi に接続し直すと、次の実行時刻に自動で再開します（すぐ試すには「今すぐ実行」）。切れている間、NAS などのネットワークのフォルダへのコピーは行わず、エラーとして知らせます。
「一部失敗」と表示されるエラーになったファイル、または読めなかったフォルダがあります。お知らせ・ログ（エラー）で内容を確認してください。読めなかったフォルダの中のファイルは、ミラーでも削除しません。
「ID またはパスワードが違います」ジョブ設定の「接続・コピー先の整理」タブで ID・パスワードを入れ直し、接続テストで確認してください。
「ドライブ E:\ がありません」外付けドライブ・USBメモリが接続されているか確認してください。
「このフォルダ名は他のPCが使っています」アプリ設定で「このPCのフォルダ名」を別の名前に変えてください。
「使用中のため次回に回します」開いているファイルは次の実行でコピーします。何度も続く場合はファイルを閉じてください。
「コピー元が空のため…削除を止めました」ミラーの安全機能です。コピー元のドライブ・フォルダが正しいか確認してください。
「ログを保管先に送れていません」ログ保管先への接続を確認してください。ログはPC内に残っているので失われません。
Windows 7 で起動しない.NET Framework 4.8 をインストールしてください（2-3）。
アイコンが見当たらない画面右下の「^」を押すと隠れたアイコンが表示されます。ドラッグして常に表示させることもできます。
メイン画面が開かない（アイコンに入れたまま長時間たった後など）v1.9 で直しました。アイコンをダブルクリックすると、元の大きさで前面に開きます。画面が見当たらないときは、別のモニターを外した後でも画面の中に戻して開きます。
重複チェックの件数が多くて画面が重い・終了してしまうv1.9 で、名前変更のまとめ表示・表示件数の上限（約5,000行）・調べ方の高速化を行いました。9章。
新しいジョブが動かない新しいジョブ・配布で加わったジョブは「無効」で作られます。メイン画面でジョブの左のチェックを入れて有効にしてください。
コピーされないファイルがある除外ルールに当てはまっていないか、ジョブ設定の テスト →「除外されるファイルを表示」で確認してください。

13. アンインストール

  1. トレイメニューの「終了」でアプリを終了します。
  2. アプリ設定で「Windows にサインインしたら自動で起動する」のチェックを外して OK を押すか、終了後に次のフォルダを削除します。
  3. %LOCALAPPDATA%\AutoCopy と %APPDATA%\AutoCopy を削除します。デスクトップのショートカットも削除します。
  4. 保存した ID・パスワードは、コントロールパネル →「資格情報マネージャー」→「Windows 資格情報」の AutoCopy: で始まる項目を削除します。

コピー先のファイルは削除されません。不要なら コピー先\_AutoCopy フォルダも削除できます。

1.16 の追加機能

大きい重複を確認済みにする

「コピー先の整理（重複チェック）の結果」で操作を「大きい重複：保存方法を選ぶ」にし、対象の行にチェックして「確認済みにする」を押します。現在のファイルは変更せず、同じジョブ・同じ相対パス・同じ内容について以後の確認を省略します。未コピーのファイルは次回の通常コピーで保存します。アプリを再起動しても記録は残り、内容が変わった場合は再確認します。

「確認済みを解除」は、選択中のジョブの確認済み記録をすべて解除します。その後「今すぐ再チェック」で確認対象を再表示できます。「実ファイルとして保存」「保管場所のテキストに置換」の選択記録は解除しません。確認の省略はコピー対象からの除外ではありません。

コピーする対象を限定する

ジョブ設定の「対象・除外」で、対象フォルダと対象拡張子を指定できます。空欄なら限定しません。フォルダはコピー元からの相対パス、拡張子は「.pdf」などを指定します。両方を指定した場合は、指定フォルダ内で指定拡張子に一致するファイルが対象です。対象外にした既存のコピーは、ミラーでも削除しません。

共有するコピー先とネットワーク処理

同じコピー先や親子関係のコピー先を使う別ジョブの元ファイルに対応するファイルは、重複整理・ミラー削除・重複テキストへの置換から保護します。他ジョブのコピー元が読めない場合も、関係するコピー先の整理を保留します。

ネットワークコピーの自動並列数を4とし、多数のファイルではコピー先の情報をフォルダごとにまとめて取得します。実際の速度はネットワークやNASによって異なります。必要に応じてジョブの並列数を調整してください。
